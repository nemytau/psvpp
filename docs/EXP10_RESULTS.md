# Experiment 10 — performance analysis, per dataset and overall

Generated by `scripts/analyze_exp10.py` from `output/rerun26__*` (merged jobs). Experiment 10 = the Experiment 8 setup rerun with first-fit insertion added to both baselines' repair pool, search-CPU-time budgets, the NOK cost model and 50 diversified test instances per size (seed 42, one trained model per reward). It ran 300-iteration restarts against the engine's old horizon of 1000 (fixed 2026-11-03; see `docs/EXPERIMENTS.md`).

**Conventions.** Unit = dataset (the best solution of the whole search). *Ratio-to-best* = a method's final cost / the cheapest final cost of any method run on that dataset in Experiment 10 (small: Adaptive, Kisialiou, RL main, RL ASt, Fixed FCR, Fixed reloc; medium and large: the first five), 1.0000 = best; averages are over the 50 datasets of a size. *Best-known fleet* f* = the fewest vessels in the final solution of any method on that dataset (not a proven bound). Every method got the same search CPU budget per dataset (Kisialiou's 5 restarts).

## 8. Headroom: portfolios and configuration selection (offline reconstruction)

Restarts are independent runs, so a run can be cut to a smaller budget (complete restarts only) and several configurations can share one budget. A *portfolio* gives each configuration a share of the dataset's budget (Kisialiou's search CPU time) and keeps the best solution found: the total compute is the same as in Experiment 10.
